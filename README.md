# FUTURE_CS_01 - Vulnerability Assessment | Task 1

## Overview and target website
This is a non-intrusive security assessment project for a live demo website, the goal of the project is to identify the common web vulnerabilities, classify them (as being High / Medium or Low risk ) and provide practical remediation steps  
**Target website: demo.testfire.net**

## Scope and Rules
**In task scope:**
- Port,  exposure and configuration analysis
- Passive Scanning, identify vulnerabilities without attacking
- Inspect headers, cookies and client side issues

**Out of Scope (not allowed)**
- Logging in or making attempts in bypasses
- Exploitation of any of the vulnerabilities
- Brute force attacks or denial of service tests

## Disclamer
This assessment project is/was performed for educational purposes on a website that is intentionally provided for security testing.
